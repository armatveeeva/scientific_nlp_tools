# Scientific NLP Tools

Python-библиотека для обработки научных текстов: семантический поиск, суммаризация, извлечение сущностей и генерация ключевых слов.

## Возможности

- **Семантический поиск**: Поиск похожих документов с использованием FAISS и Sentence Transformers
- **Суммаризация текстов**: Экстрактивная суммаризация на основе алгоритма TextRank
- **Извлечение сущностей**: Извлечение химических соединений с помощью ChemDataExtractor
- **Генерация ключевых слов**: Автоматическое выделение ключевых слов алгоритмом YAKE
- **Предобработка текста**: Очистка и подготовка научных текстов к анализу
